**Every row in this export was produced by the keyword fallback, not by Gemini.** `SentimentService._gemini_sentiment_analysis` catches all exceptions and returns `_mock_sentiment_analysis`, writing the result into `sentiments` with no marker — so a dead API key fills the collection with keyword scores that look identical to real ones.

A student trained on this data learns the keyword heuristic, not the teacher. The export is still useful for validating the training pipeline end to end, but the resulting adapter is **not** a distilled LLM and must not be described as one.

To get a real training set:

1. Put a working key in `GEMINI_API_KEY`.
2. Re-analyse the backlog (`POST /sentiments/analyze` per article, or let the scheduler refill the collection).
3. Re-run this export and confirm the `gemini` share is ~100%.
